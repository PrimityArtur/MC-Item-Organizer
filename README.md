# Item Organizer

A client-side visual inventory and palette manager for Minecraft Fabric.

---

## What the mod does

Item Organizer adds a dedicated interface to view and manage Minecraft blocks and items:

- **Color Gradient Sorting**: Reads block and item textures dynamically and arranges them by color gradient (hue, saturation, luminance), including modded blocks.
- **Hotbar Palettes**: Save groups of up to 9 blocks as custom palettes and load them directly into your hotbar with a single click.
- **Item Blocker**: Double right-click any item to hide it from the organizer view so it does not clutter your workspace.
- **Profiles**: Create and switch between multiple layouts for different building tasks or resource categories.
- **Interface Adjustments**: Adjust background blur, grid zoom, item size, palette scale, and text size from the configuration menu.

---

## Why use this mod

- **Finding matching blocks**: Helps builders find blocks that blend well together for gradients without guessing or manually checking each block texture.
- **Quick block switching**: Reduces time spent searching through the creative inventory or chests by keeping frequently used block palettes one click away.
- **Automatic mod compatibility**: Analyzes textures at runtime, so blocks from other mods are included in the color sorting automatically without manual lists.

---

## Important information before downloading

- **Client-side only**: The mod only needs to be installed on your client. It does not need to be installed on servers and can be used when connecting to vanilla, Fabric, Paper, or Purpur multiplayer servers.
- **Dependencies**: Requires Fabric Loader and Fabric API for Minecraft 1.21.10 or 1.21.11.
- **Keybinding**: Press **O** to open the interface. The key can be changed in the standard Minecraft Controls menu (`Options > Controls > Key Binds`) or in the mod's configuration menu.

---

## Controls

| Key / Action | Function |
| :--- | :--- |
| **O** | Open or close the Item Organizer screen |
| **Left Click** | Select an item or click UI buttons |
| **Double Right Click** | Hide or unhide an item (Blocker list) |
| **Escape** | Close the screen |

---

## Installation

1. Install Fabric Loader for Minecraft 1.21.10 or 1.21.11.
2. Download Fabric API and place it in your `.minecraft/mods` folder.
3. Download Item Organizer and place it in your `.minecraft/mods` folder.
4. Launch the game and press **O** to open the organizer.
